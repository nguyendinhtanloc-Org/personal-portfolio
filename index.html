PropMatch Engine — PropTech Data Lakehouse

Multi-source real-estate listings suffer from duplicate entities, inconsistent pricing/coordinates, and price anomalies — requiring a decoupled compute-storage lakehouse with zero silent data loss.

Immutable Raw & Dead-Letter storage on MinIO; Polars & Pydantic normalization to Silver GeoParquet; multi-pass blocking + NetworkX graph Entity Resolution & Z-score/IQR risk scoring into Gold via DuckDB Spatial and dbt-duckdb.

stack Python · Polars · DuckDB Spatial · dbt-duckdb · MinIO · GeoParquet · Docker

Pipeline Architecture

→
02 MinIO Raw + DLQ Immutable S3
→

→
04 Entity Resolution DuckDB + NetworkX
→
05 Gold & Spatial BI dbt-duckdb

Target estimate Zero silent data loss (DLQ + Review Queue quarantine), zero false merges in Gold, and 100% reproducible replay from immutable Raw storage

Computer Vision in progress

Metadata-Stratified Active Learning (BDD100K)

Standard uncertainty sampling in autonomous-driving object detection suffers from batch diversity collapse, degrading mAP on rare safety-critical slices (adverse weather, night).

Hybrid Top-K uncertainty filtering, square-root frequency quota allocation, and 3D Iterative Proportional Fitting (IPF / Sinkhorn) across weather, scene, and timeofday with YOLOv8n.

stack Python · PyTorch · YOLOv8 · BDD100K · IPF / Sinkhorn · pytest · Docker

Pipeline Architecture
01 BDD100K Pool Metadata index
→
02 Hybrid Top-K Box uncertainty
→
03 IPF / Sinkhorn 3D Stratification
→
04 YOLOv8n Loop 3 seeds × 6 runs
→
05 Statistical Test Paired t-test

Target estimate +2.08% mAP50 on adverse_weather domain; batch Shannon entropy reaches 5.20 vs 3.84 bits (p = 0.00076, Cohen's d = 20.93)
